
# Django Homework Project

Этот проект — базовое Django-приложение, созданное в рамках учебного задания. Он содержит главную страницу и страницу с контактной информацией, реализованные с использованием шаблонов и маршрутов.

## 🔧 Установка и запуск

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/Lorend359/django_hw.git
   cd django_hw
   ```

2. Установите зависимости (если используется Poetry):
   ```bash
   poetry install
   ```

3. Выполните миграции:
   ```bash
   poetry run python manage.py migrate
   ```

4. Запустите сервер:
   ```bash
   poetry run python manage.py runserver
   ```

## 📁 Структура

- `catalog/` — основное приложение с контроллерами и шаблонами
- `config/` — конфигурация проекта
- `templates/` — HTML-шаблоны
- `static/` — директория для будущих статических файлов

## ⚙️ Возможности

- Главная страница (`/`)
- Страница контактов (`/contacts/`)
- Шаблонизация с Bootstrap

## 📌 Примечание

Проект находится в разработке и будет дополняться новым функционалом.
